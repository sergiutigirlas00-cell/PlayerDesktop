pate după cum le folosești:

🔧 Setup (o singură dată)

┌────────────────────────────────────────┬─────────────────────────────────────────────┐
│                Comandă                 │                   Ce face                   │
├────────────────────────────────────────┼─────────────────────────────────────────────┤
│ git config --global user.name "Numele" │ Setează numele care apare la commit-uri     │
├────────────────────────────────────────┼─────────────────────────────────────────────┤
│ git config --global user.email "email" │ Setează emailul pentru commit-uri           │
├────────────────────────────────────────┼─────────────────────────────────────────────┤
│ git init                               │ Transformă folderul curent într-un repo Git │
├────────────────────────────────────────┼─────────────────────────────────────────────┤
│ git clone <link>                       │ Descarcă un repo de pe GitHub pe PC         │
└────────────────────────────────────────┴─────────────────────────────────────────────┘

📝 Lucrul de zi cu zi (ce ai făcut tu la PAD)

┌───────────────────────┬────────────────────────────────────────────────────────────────┐
│        Comandă        │                            Ce face                             │
├───────────────────────┼────────────────────────────────────────────────────────────────┤
│ git status            │ Arată ce fișiere s-au modificat, ce e adăugat și ce nu         │
├───────────────────────┼────────────────────────────────────────────────────────────────┤
│ git add <fișier>      │ Pune un fișier în „staging” (îl pregătește pentru commit)      │
├───────────────────────┼────────────────────────────────────────────────────────────────┤
│ git add .             │ Pune toate fișierele modificate în staging                     │
├───────────────────────┼────────────────────────────────────────────────────────────────┤
│ git commit -m "mesaj" │ Salvează un „snapshot” local cu un mesaj despre ce ai schimbat │
├───────────────────────┼────────────────────────────────────────────────────────────────┤
│ git push              │ Urcă commit-urile tale pe GitHub                               │
├───────────────────────┼────────────────────────────────────────────────────────────────┤
│ git pull              │ Descarcă ultimele schimbări de pe GitHub în folderul tău       │
└───────────────────────┴────────────────────────────────────────────────────────────────┘

Flow-ul clasic: git add . → git commit -m "ce am făcut" → git push

🔍 Verificare / istoric

┌───────────────────┬──────────────────────────────────────────────────────────────┐
│      Comandă      │                           Ce face                            │
├───────────────────┼──────────────────────────────────────────────────────────────┤
│ git log           │ Lista commit-urilor (autor, dată, mesaj)                     │
├───────────────────┼──────────────────────────────────────────────────────────────┤
│ git log --oneline │ Aceeași listă, dar compactă, câte un rând pe commit          │
├───────────────────┼──────────────────────────────────────────────────────────────┤
│ git diff          │ Arată exact ce linii ai schimbat și încă n-ai adăugat cu add │
└───────────────────┴──────────────────────────────────────────────────────────────┘

🌿 Branch-uri (ramuri)

┌─────────────────────────────────────────┬──────────────────────────────────────────────────┐
│                 Comandă                 │                     Ce face                      │
├─────────────────────────────────────────┼──────────────────────────────────────────────────┤
│ git branch                              │ Arată branch-urile, cel curent e marcat cu *     │
├─────────────────────────────────────────┼──────────────────────────────────────────────────┤
│ git branch <nume>                       │ Creează un branch nou                            │
├─────────────────────────────────────────┼──────────────────────────────────────────────────┤
│ git checkout <nume> / git switch <nume> │ Te mută pe alt branch                            │
├─────────────────────────────────────────┼──────────────────────────────────────────────────┤
│ git checkout -b <nume>                  │ Creează branch-ul și te mută direct pe el        │
├─────────────────────────────────────────┼──────────────────────────────────────────────────┤
│ git merge <nume>                        │ Unește branch-ul <nume> în cel pe care ești acum │
└─────────────────────────────────────────┴──────────────────────────────────────────────────┘

🌐 Remote (legătura cu GitHub)

┌──────────────────────────────┬────────────────────────────────────────────────────────────────────────┐
│           Comandă            │                                Ce face                                 │
├──────────────────────────────┼────────────────────────────────────────────────────────────────────────┤
│ git remote add origin <link> │ Leagă repo-ul local de unul de pe GitHub                               │
├──────────────────────────────┼────────────────────────────────────────────────────────────────────────┤
│ git remote -v                │ Arată la ce repo GitHub e legat                                        │
├──────────────────────────────┼────────────────────────────────────────────────────────────────────────┤
│ git push -u origin main      │ Primul push: urcă branch-ul main și îl ține minte pentru data viitoare │
└──────────────────────────────┴────────────────────────────────────────────────────────────────────────┘

↩️ Anulare

┌───────────────────────────────┬──────────────────────────────────────────────────────────────┐
│            Comandă            │                           Ce face                            │
├───────────────────────────────┼──────────────────────────────────────────────────────────────┤
│ git restore <fișier>          │ Aruncă modificările nesalvate dintr-un fișier ⚠️ (le pierzi) │
├───────────────────────────────┼──────────────────────────────────────────────────────────────┤
│ git restore --staged <fișier> │ Scoate fișierul din staging, fără să pierzi modificările     │
├───────────────────────────────┼──────────────────────────────────────────────────────────────┤
│ git reset --soft HEAD~1       │ Anulează ultimul commit, dar modificările rămân
