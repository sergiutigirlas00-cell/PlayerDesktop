# 🎬 PlayerDesktop

Aplicație desktop simplă pentru redarea fișierelor audio și video, realizată în C# (.NET 8).

Proiect demonstrativ pentru **Lucrarea individuală nr. 1** – *Planificarea aplicațiilor desktop*, CEITI.

## ✨ Funcționalități
- Redarea fișierelor MP4 și MP3
- Control Play / Pauză / Stop
- Liste de redare (playlist)

## 💻 Cerințe de sistem
- Windows 10 / 11
- .NET 8 Runtime

## 🚀 Instalare și rulare
1. Descarcă ultima versiune din secțiunea **Releases**
2. Dezarhivează și rulează `PlayerDesktop.exe`

Sau din codul sursă:
```
git clone https://github.com/sergiutigirlas00-cell/PlayerDesktop.git
cd PlayerDesktop
dotnet run
```
